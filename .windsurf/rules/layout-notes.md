# Physical layout notes are part of the schematic deliverable

User ruling (2026-10-12): once the circuit is represented correctly in the
schematic we proceed to placement/routing — so **any and all physical layout
intent must be captured as we design**, not deferred to the layout phase.

- Every schematic sheet in `utils/gen_kicad.py` carries `LAYOUT`-prefixed text
  blocks for placement-critical circuitry (regulator adjacency, Kelvin taps,
  channel-zone boundaries, connector-entry orientation, pour isolation,
  thermal/heatsink coupling, keep-outs).
- When a decision has physical consequences (dual-mono zoning, an LDO that
  must sit at its load, a sense tap location, a bead-island topology), write
  it into the sheet text at the same time as the circuit — alongside the part
  it applies to.
- The PREREG sheet (`on_board=no` parts) is a separate PCB: its layout notes
  describe Tub-1 placement (transformer terminals, diode heatsinking, cap
  bank grouping, SEAF mate orientation), not main-board locations.
- Cross-board constraints (SEAF pad maps, board spacing, connector-side
  orientation) live in `docs/SEAF_PIN_ASSIGNMENTS.md`; thermal/zone policy in
  `docs/SYSTEM_ARCHITECTURE.md`. Keep them consistent with the sheet notes.
- Generated files are regenerated by `utils/gen_kicad.py` — never put layout
  notes only in the generated `.kicad_sch` files; they will be overwritten.
